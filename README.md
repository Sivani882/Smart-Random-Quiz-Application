# Smart Random Quiz Application

## Project Overview
Smart Random Quiz Application is a beginner-friendly Python project that allows users to play quizzes at different difficulty levels. It displays random questions, checks answers, calculates scores, and provides feedback.

## Technologies Used
- Python
- Visual Studio Code
- Random module

## Features
1. Three difficulty levels: Easy, Medium, and Hard.
2. Random selection of five questions.
3. Four multiple-choice options for each question.
4. Automatic answer checking.
5. Displays the correct answer for wrong responses.
6. Calculates the final score and percentage.
7. Provides feedback based on the score.
8. Allows users to play again.

## How the Project Works
1. The application welcomes the user.
2. The user selects a difficulty level.
3. The program randomly selects five questions.
4. Each question is displayed with four options.
5. The user enters an answer (A, B, C, or D).
6. The program checks the answer and updates the score.
7. After all questions, the final score and percentage are displayed.
8. The user can choose to play again or exit.

## How to Run the Project
1. Install Python on your computer.
2. Open the project folder in Visual Studio Code.
3. Open the `quiz.py` file.
4. Run the Python file in the terminal.
5. Select a difficulty level and start playing.
